# Your first document

Start with the [quickstart in the README](README.md#quickstart). It brings up the stack with
Docker Compose, has you sign in to the console, and walks one sample PDF through OCR, extraction,
checking fields, and a quality report, with no API key.

This file used to hold docdoc's original MVP technical design, which still described a Python
library and local commands that docdoc no longer offers
([ADR-0027](docs/adr/0027-service-only-surface.md)). The specifications under `specs/` cite its
sections; read it from history with `git show 44bd48e:FIRST_DOC.md`.
